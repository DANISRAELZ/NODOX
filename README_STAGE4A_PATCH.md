# NODOX Stage 4A — explicit evolutionary evidence contract

This stage adds a strict, auditable contract for evolutionary evidence.

It does not:

- query external providers;
- change Functional Node Theory weights;
- change historical proxy scores;
- change default ranking behavior;
- modify frozen result directories.

It adds:

- a typed evolutionary evidence record;
- conservative provenance and mapping validation;
- explicit separation of evaluable and missing states;
- independence-group accounting;
- regression tests preventing missing or proxy values from becoming explicit.
