# Mycobacterium tuberculosis H37Rv Controlled Snapshot

This directory contains a minimal controlled reference snapshot for
`Mycobacterium tuberculosis` H37Rv.

It exists to validate the multiorganism curated snapshot contract. It is not a
fresh online acquisition, not a demo dataset, not a proxy inference layer and
not a replacement for user-curated experimental evidence.

## Scope

- Organism: `Mycobacterium tuberculosis`
- Strain: `H37Rv`
- Taxon id: `83332`
- Evidence status: `controlled_reference_snapshot`
- Network policy: `no_fresh_network_calls`

## Interpretation Limits

- STRING and UniProt were not queried for this snapshot.
- The functional annotations are controlled reference entries for audit and
  validation only.
- Missing genes, features or layers are not evidence of biological absence.
- Missing evidence must not be interpreted as low evolutionary escape risk.
- This snapshot must remain separate from PAO1 and Corynebacterium examples.
