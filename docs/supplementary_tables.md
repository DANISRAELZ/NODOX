# Supplementary Tables

## Generated Publication Tables

The publication package includes six main tables:

- `publication_table_1_top_candidates.csv`;
- `publication_table_2_score_decomposition.csv`;
- `publication_table_3_evolutionary_risk.csv`;
- `publication_table_4_sensitivity_stability.csv`;
- `publication_table_5_evidence_provenance.csv`;
- `publication_table_6_baseline_comparison.csv`.

## Evidence and Provenance

Evidence and provenance fields should be reviewed together with candidate ranks. Limitation labels are retained so manuscript readers can distinguish curated, demo, proxy, missing and not assessed inputs.

## Sensitivity and Ranking Stability

Sensitivity tables report scenario-specific rank movement. `rank_delta_vs_base` and the derived maximum absolute rank delta used in the figures indicate internal ranking stability under configured perturbations.

## Demo Limitations

The publication demo is intended to demonstrate reproducible software behavior. It should not be interpreted as a claim that any listed candidate has been independently confirmed.
