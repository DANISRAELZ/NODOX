# Nodos Funcionales: Theory First

## Idea central

Este proyecto no existe solo para producir rankings. Existe para
operacionalizar la Teoria de Nodos Funcionales.

La teoria dirige al software:

```text
postulados biologicos -> capas de evidencia -> variables -> scores -> ranking
```

## Que significa un score

Un score no es una verdad absoluta. Es una forma reproducible de resumir una
hipotesis terapeutica con la evidencia disponible.

Un ranking alto significa:

- el candidato parece relevante bajo las reglas actuales;
- las capas disponibles convergen en alguna medida;
- la interpretacion debe leerse junto con procedencia, confianza y faltantes.

No significa:

- validacion experimental;
- disponibilidad de farmaco;
- recomendacion clinica;
- ausencia garantizada de resistencia.

## Multi-organismo

El sistema esta disenado para cualquier organismo bacteriano con datos
compatibles. Los organismos demo son ejemplos, no la definicion del modelo.

## Eje evolutivo

La capa evolutiva es central. El proyecto evalua riesgo de escape, restriccion
evolutiva, redundancia, paralogia, movilidad, HGT, recombinacion y asociacion
con resistencia cuando hay evidencia disponible.

## Procedencia y confianza

La procedencia modifica la confianza. Datos de usuario, snapshots curados,
fuentes online reales, proveedores controlados, proxies, demos y faltantes no
tienen el mismo peso conceptual.
