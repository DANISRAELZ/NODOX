# Demo Expected Outputs Manifest

## Purpose

This manifest lists expected artifacts for the final Pseudomonas aeruginosa publication demo. These artifacts support workflow validation and reproducibility. They are not experimental validation, do not establish clinical utility and do not confirm therapeutic validity.

Candidate ranking requires downstream validation before biological, clinical or therapeutic claims.

## Expected Artifacts

| Artifact | Status | Purpose | Publication relevance | Interpretation boundary |
| --- | --- | --- | --- | --- |
| `ranking_nodos.csv` | Required | Main ranked output of candidate nodes. | Supports reproducible reporting of computational prioritization. | Ranking is not biological, clinical or experimental validation. |
| `report_phase2.md` | Required | Human-readable report or equivalent report summarizing the run. | Supports methods and demo narrative. | Report language must remain conservative. |
| `candidate_explanations_simple.csv` | Required when generated by the pipeline path | Compact candidate explanation table. | Helps readers inspect why candidates were prioritized. | Explanations are computational summaries, not target confirmation. |
| `candidate_audit.csv` | Required when generated by the pipeline path | Auditable candidate-level score and evidence details. | Supports traceability and reproducibility review. | Auditability does not establish clinical utility. |
| `evidence_strength_audit.csv` | Required when generated by the pipeline path | Evidence-strength and confidence audit. | Shows evidence confidence and limitations. | Evidence confidence remains separate from therapeutic priority. |
| `layer_resolution_summary.csv` | Required when generated by the pipeline path | Summary of resolved evidence layers and provenance. | Supports source and provenance transparency. | Resolved layers do not automatically validate biological truth. |
| `publication_package/` | Required for publication package review, context-dependent for raw demo checks | Manuscript/demo tables, figures, manifests and summaries. | Supports publication artifact review. | A publication package is not experimental validation. |
| `run_manifest.json` | Context-dependent | Records controlled run metadata when generated by GUI or runner paths. | Supports reproducible execution review. | Manifest metadata does not validate candidates. |
| `pipeline_stdout.log` and `pipeline_stderr.log` | Context-dependent | Captures execution logs for controlled GUI runs. | Supports troubleshooting and auditability. | Logs are workflow evidence only. |

## Expected Reference Location

The stable reference demo artifacts live under:

```text
examples/pseudomonas_aeruginosa_publication_demo/expected_tables/
examples/pseudomonas_aeruginosa_publication_demo/expected_outputs/
```

GUI-generated publication packages must remain inside the selected isolated GUI run directory:

```text
results/gui_runs/<run_id>/publication_package/
```

Review comparison output must remain inside:

```text
results/gui_runs/<run_id>/review/
```

## Boundaries

These artifacts support workflow validation and reproducibility. They are not experimental validation, they do not establish clinical utility and they do not validate therapeutic targets. Candidate ranking requires downstream validation.
