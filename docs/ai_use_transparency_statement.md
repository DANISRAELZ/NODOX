# AI-Use Transparency Statement

## Draft Statement

AI tools may have assisted with drafting, refactoring, testing, documentation organization and prompt-based development in this repository. All AI-assisted outputs require human review before acceptance.

Human reviewers remain responsible for:

- scientific interpretation;
- code acceptance;
- validation boundaries;
- licensing;
- privacy;
- final release decisions.

AI assistance does not constitute biological validation, clinical validation, experimental validation, authorship or external evidence. It also does not replace scientific responsibility, privacy review, licensing review or release approval.

This statement is intended as a transparent and conservative starting point. Adapt the wording to the relevant journal, repository, funder or institutional policy before public release or manuscript submission.
