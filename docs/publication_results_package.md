# Publication Results Package

## Purpose

`results/publication_package/` consolidates local result tables, internal validation reports and interpretative figures for publication review. The package is a reproducible computational demonstration of candidate functional node prioritization.

## Tables and Reports

- `publication_table_1_top_candidates.csv`
- `publication_table_2_score_decomposition.csv`
- `publication_table_3_evolutionary_risk.csv`
- `publication_table_4_sensitivity_stability.csv`
- `publication_table_5_evidence_provenance.csv`
- `publication_table_6_baseline_comparison.csv`
- `publication_internal_validation.md`
- `publication_baseline_comparison.md`

## Figures

The `figures/` folder is generated by the publication package builder.

- `figure_1_top_candidates_meta_priority.png`: main bar chart for candidate ranking by `meta_priority_score`.
- `figure_2_priority_vs_confidence.png`: scatter plot separating `therapeutic_priority_score` from `evidence_confidence_score`.
- `figure_3_score_decomposition.png`: score decomposition view for interpretability.
- `figure_4_evolutionary_risk_vs_priority.png`: evolutionary escape risk compared with therapeutic priority.
- `figure_5_ranking_stability.png`: maximum absolute rank movement across sensitivity scenarios.
- `figure_6_therapeutic_role_distribution.png`: distribution of candidate therapeutic roles.
- `publication_figures_interpretation.md`: figure-by-figure source and interpretation notes.

SVG versions are also generated when each corresponding figure has enough required columns.

## Interpretation Boundaries

Figures are descriptive outputs from local computational tables. They are not experimental, pharmacological or clinical confirmation. `therapeutic_priority_score` and `evidence_confidence_score` remain separate model outputs, and provenance labels such as `demo_only`, `preliminary`, `proxy`, `missing`, `not_assessed` and `insufficient_evidence` should remain visible during manuscript interpretation.

## Reproduction

```bash
python -m src.nodos_funcionales.publication_package_builder --results-dir results --output-dir results/publication_package
```
