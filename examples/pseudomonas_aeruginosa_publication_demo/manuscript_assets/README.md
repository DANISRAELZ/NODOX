# Manuscript assets

This directory indexes manuscript-facing material for the
`Pseudomonas aeruginosa` publication demo.

## Sources

- Candidate table template:
  `examples/pseudomonas_aeruginosa_publication_demo/expected_outputs/publication_candidate_summary.csv`
- Phase 2 results note:
  `docs/pseudomonas_aeruginosa_publication_demo_phase2_results.md`
- Phase 3 manuscript material:
  `docs/pseudomonas_aeruginosa_publication_demo_phase3_manuscript_material.md`

## Status

These files are preliminary manuscript materials for a reproducible
prioritization demo. They are not clinical validation and not experimental
validation. They should be used to organize figures, tables, methods text, and
reviewer-facing interpretation without changing the scientific scoring logic.
