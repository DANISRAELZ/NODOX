# Expected publication tables

This directory contains expected output structures for the publication demo.
The CSV files are headers-only templates unless generated by a controlled
pipeline run. They do not contain fabricated scores, candidates, validations, or
clinical claims.

Use these files to check that manuscript-facing outputs remain interpretable:

- priority scores are separate from evidence confidence;
- evidence quality describes evidence, not automatic validation;
- provenance remains visible;
- unresolved evidence and evolutionary risk remain visible.
